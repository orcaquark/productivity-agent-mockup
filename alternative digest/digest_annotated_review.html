The unified daily digest

One of three directions explored for the "For You" home screen — alongside a conversational message log and a swipeable card deck. This one drops the card-and-thread layout entirely: the briefing, nudge, trend, missed tasks, and kudos become a single continuous read, styled closer to a personal note than a dashboard of widgets. Items tagged OPEN are known gaps worth a ticket; items tagged UNCHANGED are carried over from the card version as-is because nothing about this alternative required touching them.

Scope note: only the "For You" home screen changes here. The personalization onboarding and settings screens reviewed alongside the card version are unaffected and aren't re-annotated in this document.

Gained

  • Reads as a single narrative instead of a grid of widgets
  • One consistent link pattern for expanding and committing
  • Trend percentages are explained in context
  • Full task names wrap instead of truncating

Traded away

  • Less information is visible at once
  • Insight and action have less visual distinction
  • No progress marker when reading is interrupted
  • Inline links have smaller tap targets

What changed, and why
1
One read, not five things to skim
The card-thread layout supported at-a-glance scanning and actions in any order. This version is a single top-to-bottom read, prioritizing a personal-note feel over skimmability.
2
No .card, no .node-dot — spacing and type do the separating
Spacing and typography separate content. Hairline dividers appear only before "What got missed" and the closing kudos line, using the card version's existing rule color and border-top pattern.
3
The percentage moves into the sentence, not a standalone numeral
The card version's conflicting "no single score here" copy was removed while keeping the 82% weekly and 69% four-week values. Here, both values appear in prose rather than as dashboard stats. The original chart remains: seven daily bars and four weekly bars behind "See full month," now placed directly in the reading flow. The month disclosure uses a white backing so its light bars remain visible against the violet panel.
4
Full task names wrap instead of truncating
Task names wrap to additional lines instead of being truncated with an ellipsis in a fixed-width row.
Two link treatments, one rule
5
Mono + caret reveals, underline commits
JetBrains Mono links with rotating carets reveal information: "Why am I seeing this" and "See full month." Underlined Inter links perform actions: "Move it," "Not now," "Send kudos," "Skip," missed-task actions, and the Gym ring link. This replaces the card version's separate chip, why-link, and trend-toggle patterns.
6
The insight/action distinction survives without chips
Read-only insights use italic body text; actions use sage underlined links. The Gym ring link opens the unchanged ring explainer modal. This distinction is subtler than the card version's two-color, two-icon chips and should be tested for action clarity.
Resolving in place
7
Every action rewrites its own sentence, not a separate row
Actions update inline where the original sentence appeared—for example, "Moved to 8:40am ✓ — Undo." The same pattern applies to missed items and kudos. Undo remains available wherever it existed previously.
8
The nudge quote is the one place that still looks like a "card"
The nudge uses a violet left rule instead of a bordered card. It intentionally interrupts the reading flow because moving a task is a decision; all other content remains continuous.
Cold start & honesty
9
Cold start is one short, unstyled paragraph
The empty state is a short paragraph explaining what data is missing and when personalization becomes available. No card frame or invented pattern is used.
10
"Add friends" is back — resolved, not just reworded
"Add friends" now opens the shared placeholder modal used by the Gym ring link. The modal changes its icon, title, and body by destination and explains that adding a friend requires a request and acceptance, directing users to the Friends tab rather than implying one-tap completion.
Carried over unchanged
11
State switcher and navbarUNCHANGED
The preview-only Active/New user switcher and five-tab navbar are unchanged, including accessibility behavior. They were outside the scope of this layout update. The ring modal changed because it is now shared by two destinations.
12
Same underlying data, same copy voiceUNCHANGED
The digest uses the same five data points as the card version: rings closed, nudge reasoning, weekly trend, two missed tasks, and Jordan's streak. Only the presentation changed.
Open
13
Task names are still fully readable on a shared or unlocked screenOPEN
This remains unresolved from the card review. Task names such as "Submit expense report" appear in plain text, making future selective blurring harder without also affecting surrounding copy.
14
Jordan's streak still surfaces without Jordan's consentOPEN
Unchanged from the card version: a friend's activity is shown to another user without a friend-side opt-in.
15
Inline text links are a smaller, harder-to-aim target than full-width buttonsOPEN
"Move it" and "Not now" replaced 42px-tall buttons with line-height-sized links. Run a touch-target review before launch, especially for adjacent "Skip" and "Undo" links.
16
No indication of how far into the digest you've readOPEN
Unlike a feed, the digest provides no progress cue. Users interrupted mid-read cannot easily see where they stopped.

Considered, not yet designed

These issues require work beyond this alternative and should be tracked in the specification.

  • A "read so far" marker or pagination for longer digests
  • Layout behavior for multiple nudges or more than two missed tasks
  • A "blur sensitive text" setting for the issue in note 13
  • Friend-side consent for displaying streaks
  • RTL mirroring for the nudge blockquote's left violet rule
  • Localization of day and week abbreviations
  • Loading and network-error states
  • A "sent" timestamp to reinforce the digest framing
  • A formal touch-target audit for all inline actions

Guardrails these decisions map back to

Principles used to evaluate this layout, including one specific to its chrome-free presentation.

Tone & framing

  • Describe, don't judge — use neutral language for patterns and reasons
  • The score lives in a sentence, not a numeral — show percentages in prose, not as standalone stats

Reversibility

  • Undo where it's cheap — preserve Undo for nudge, missed-task, and kudos actions
  • One beat still interrupts the flow on purpose — the nudge remains visually distinct because it requires a decision

Honesty about state

  • Cold start is explained, not blank — state what is missing without inventing a pattern
  • No dead links — "Add friends" opens a real destination modal

One consistent primitive

  • Two link types, used everywhere — mono caret reveals; underlines commit actions
  • Spend the one visual accent deliberately — only the nudge uses the violet rule; the rest stays quiet
